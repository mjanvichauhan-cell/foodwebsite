# 🍽️ Food Website

A responsive food/restaurant website built using **HTML, CSS, and JavaScript**.  
The website provides an attractive food menu interface with category filtering, responsive navigation, scroll animations, and interactive menu buttons.

![foodwebsite](foodwebsite.png)

## 🚀 Features

- 📱 Responsive navigation menu
- 🍔 Food/menu card display
- 🔍 Menu category filtering
- ➕ Add button interaction
- ✅ Button confirmation animation
- 🎨 Modern and responsive UI
- 📱 Mobile-friendly design
- 🧭 Smooth navigation experience

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling and responsive design
- **JavaScript** – Interactivity and dynamic functionality
- **Remix Icon** – Icons used throughout the website

## 🎯 Project Purpose

This project was created to practice frontend web development concepts including:

- DOM manipulation
- JavaScript event listeners
- CSS animations
- Responsive layouts
- Category filtering
- Intersection Observer API
- Interactive UI components
